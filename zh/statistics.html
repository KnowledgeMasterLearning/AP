课程介绍

AP STATISTICS · COURSE OVERVIEW

AP 统计学课程共分为 5 个单元，围绕四个核心概念展开： 数据探索、概率与随机变量、 统计推断、变量间关系。

单元分布与考试占比

Unit 1 Exploring One-Variable Data and Collecting Data 单变量数据探索与数据收集 20–30%
Unit 2 Probability, Random Variables, and Probability Distributions 概率、随机变量与概率分布 15–25%
Unit 3 Inference for Categorical Data: Proportions 分类数据的推断：比例 15–25%
Unit 4 Inference for Quantitative Data: Means 定量数据的推断：均值 10–20%
Unit 5 Regression Analysis 回归分析 10–20%
说明：Unit 1 占比最高（20–30%），是整个课程的基础。 Unit 3 和 Unit 4 合计约占考试的 25–45%， 是统计推断的核心部分，也是 FRQ 的高频考点。

Unit 1 · Exploring One-Variable Data and Collecting Data单变量数据探索与数据收集

20–30%

建立统计思维方式和数据分析基础，同时涵盖数据收集的方法。

  • 1.1 Introducing Statistics 统计导论统计研究的组成部分；总体与样本；参数与统计量；in context 的含义
  • 1.2 Variables 变量observational unit；variable；categorical vs. quantitative；discrete vs. continuous
  • 1.3 Tabular Representation 单分类变量的表格表示frequency table；relative frequency table；proportions、percentages、ratios
  • 1.4 Graphical Representations for One Categorical Variable 单分类变量的图形表示bar chart；pie chart；用图形支撑结论；比较多个数据集
  • 1.5 Graphical Representations for One Quantitative Variable 单定量变量的图形表示histogram；stem-and-leaf plot；dotplot；bin width 的影响
  • 1.6 Descriptions for One Quantitative Variable 单定量变量分布的描述SOCS 框架；skewed left/right；unimodal/bimodal/uniform；outliers、gaps、clusters
  • 1.7 Summary Statistics for One Quantitative Variable 单定量变量的汇总统计mean、median、Q1、Q3、percentile；range、IQR、standard deviation、variance；outlier 判定；resistant vs. non-resistant
  • 1.8 Graphical Representations of Summary Statistics 汇总统计的图形表示five-number summary；boxplot；mean 与 median 的关系反映分布形状
  • 1.9 Comparisons of Distributions 单定量变量分布的比较比较 shape、center、spread、outliers；back-to-back stem plot；side-by-side boxplot；z-score
  • 1.10 The Investigative Question Revisited 调查性问题与数据收集investigative question 的三要素；census；experiment vs. observational study；prospective vs. retrospective；confounding variable
  • 1.11 Random Sampling 随机抽样sampling with/without replacement；SRS；stratified；cluster；systematic；各方法的适用场景
  • 1.12 Potential Problems with Sampling 抽样的潜在问题bias 的定义；voluntary response bias；undercoverage bias；nonresponse bias；response bias
  • 1.13 Experimental Design 实验设计experiment 的组成；random assignment 与因果推断；control、placebo、blinding；completely randomized、randomized block、matched pairs

Unit 2 · Probability, Random Variables, and Probability Distributions概率、随机变量与概率分布

15–25%

建立概率论基础，是后续统计推断的理论支撑。

  • 2.1 Distributions of Two Categorical Variables 两个分类变量的表格与图形表示two-way table；joint/marginal/conditional relative frequency；side-by-side bar chart；segmented bar chart；mosaic plot；association
  • 2.2 Summary Statistics for Two Categorical Variables 两个分类变量的汇总统计joint、marginal、conditional relative frequency；用条件分布比较与支撑结论
  • 2.3 Estimating Probabilities Using Simulation 用模拟估计概率random process；outcome；event；simulation 的步骤；law of large numbers
  • 2.4 Introduction to Probability 概率导论sample space；theoretical probability；概率的范围；complement rule
  • 2.5 Mutually Exclusive Events 互斥事件joint probability；intersection；mutually exclusive 的条件 P(A∩B) = 0
  • 2.6 Conditional Probability 条件概率P(A|B) = P(A∩B)/P(B)；general multiplication rule P(A∩B) = P(A)·P(B|A)
  • 2.7 Independent Events and Unions 独立事件与事件的并集independence 的条件 P(A∩B) = P(A)·P(B)；independent vs. mutually exclusive；general addition rule
  • 2.8 Introduction to Random Variables 随机变量与概率分布导论random variable；discrete random variable；probability distribution 的条件；cumulative probability distribution
  • 2.9 Parameters of Random Variables 随机变量的参数expected value μ_X = ΣxᵢP(xᵢ)；standard deviation；variance；结合上下文解释
  • 2.10 The Binomial Distribution 二项分布BINS 条件；binomial probability formula；mean μ_X = np，σ_X = √(np(1−p))；用 simulation 估计
  • 2.11 The Normal Distribution 正态分布continuous random variable；normal distribution 的特征；standard normal distribution；empirical rule（68–95–99.7）；用 z-score 计算概率；求区间边界
  • 2.12 Sampling Distributions and CLT 抽样分布与中心极限定理sampling distribution；simulation；randomization distribution；central limit theorem；样本量对抽样分布的影响

Unit 3 · Inference for Categorical Data: Proportions分类数据的推断：比例

15–25%

聚焦于单样本和双样本比例问题的统计推断。

  • 3.1 Estimators 估计量point estimator；unbiased estimator；样本比例 p̂ 作为 p 的估计量
  • 3.2 Sampling Distributions for Sample Proportions 样本比例的抽样分布p̂ 的 mean、standard deviation；正态近似条件（np ≥ 10，n(1−p) ≥ 10）
  • 3.3 Constructing a Confidence Interval 构造总体比例的置信区间confidence interval 的结构；critical value；margin of error；解释 confidence level
  • 3.4 Justifying a Claim 基于置信区间支撑结论用 CI 判断是否支持某个 claim；结合上下文解释
  • 3.5 Setting Up a Test 建立总体比例的假设检验null hypothesis H₀；alternative hypothesis Hₐ；one-sided vs. two-sided
  • 3.6 p-Values p 值p-value 的定义与解释；significance level α；用 p-value 做决策
  • 3.7 Carrying Out a Test 进行总体比例的假设检验检验统计量 z；计算 p-value；结论的完整表述
  • 3.8 Potential Errors 假设检验中的潜在错误Type I error；Type II error；power；α 与 β 的关系
  • 3.9 Sampling Distributions for Difference 样本比例之差的抽样分布p̂₁ − p̂₂ 的 mean 与 standard deviation；正态近似条件
  • 3.10 CI for Difference 构造两总体比例之差的置信区间CI 的计算与解释
  • 3.11 Justifying a Claim 基于两比例之差的置信区间支撑结论CI 是否包含 0 的判断
  • 3.12 Setting Up a Test for Difference 建立两总体比例之差的假设检验H₀：p₁ − p₂ = 0；pooled proportion
  • 3.13 Carrying Out a Test for Difference 进行两总体比例之差的假设检验检验统计量；p-value；结论
  • 3.14 Setting Up a Chi-Square Test 建立卡方齐性或独立性检验expected counts；chi-square 统计量；自由度
  • 3.15 Carrying Out a Chi-Square Test 进行卡方齐性或独立性检验计算 chi-square；p-value；结论与解释

Unit 4 · Inference for Quantitative Data: Means定量数据的推断：均值

10–20%

聚焦于单样本和双样本均值问题的统计推断。

  • 4.1 Sampling Distributions for Sample Means 样本均值的抽样分布x̄ 的 mean 与 standard deviation；central limit theorem；正态条件
  • 4.2 Constructing a Confidence Interval 构造总体均值或均值差的置信区间t-distribution；degrees of freedom；CI 的计算与解释
  • 4.3 Justifying a Claim 基于均值置信区间支撑结论结合上下文解释 CI
  • 4.4 Setting Up a Test 建立总体均值或均值差的假设检验H₀ 与 Hₐ；one-sample t-test
  • 4.5 Carrying Out a Test 进行总体均值或均值差的假设检验t-statistic；p-value；结论
  • 4.6 Sampling Distributions for Difference 两样本均值之差的抽样分布x̄₁ − x̄₂ 的 mean 与 standard deviation；条件
  • 4.7 CI for Difference 构造两总体均值之差的置信区间two-sample t-interval；计算与解释
  • 4.8 Justifying a Claim 基于两均值之差的置信区间支撑结论CI 是否包含 0
  • 4.9 Setting Up a Test for Difference 建立两总体均值之差的假设检验H₀：μ₁ − μ₂ = 0；two-sample t-test
  • 4.10 Carrying Out a Test for Difference 进行两总体均值之差的假设检验t-statistic；p-value；结论

Unit 5 · Regression Analysis回归分析

10–20%

研究两个定量变量之间的关系，建立并评估线性回归模型。

  • 5.1 Graphical Representations 两个定量变量之间的图形表示scatterplot；direction、form、strength、outliers；explanatory vs. response variable
  • 5.2 Correlation 相关correlation coefficient r 的计算与解释；r 的性质；相关不等于因果
  • 5.3 Linear Regression Models 线性回归模型least-squares regression line；slope 与 intercept 的解释；预测
  • 5.4 Residuals 残差residual 的定义与计算；residual plot；判断线性模型是否合适
  • 5.5 Least-Squares Regression 最小二乘回归least-squares criterion；回归线的计算；r² 的解释；outliers 与 influential points
